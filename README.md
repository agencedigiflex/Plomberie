# Harguindeguy Aldaz Plomberie — Homepage

Intégration HTML/CSS de la maquette Figma « Homepage version 2 »
(fichier *Projets clients*, nœud `153:471`).

## Structure

```
index.html            Page d'accueil (sections : hero, activités, secteur, équipe,
                      partenaires, avis, contact, footer)
assets/css/fonts.css  Polices auto-hébergées (Jost, Inter, Hanken Grotesk,
                      Gabarito, Google Sans Flex — sous-ensemble latin, SIL OFL)
assets/css/style.css  Styles + responsive (1024px / 640px)
assets/js/main.js     Menu mobile
assets/img/           Photos et logo exportés de Figma
assets/icons/         Icônes SVG exportées de Figma
```

Aucune dépendance ni build : ouvrir `index.html` dans un navigateur.

## À compléter

- Numéro de téléphone réel (`05 XX XX XX XX` dans la maquette).
- Traitement du formulaire de contact (`action="#"` pour l'instant), par exemple
  via un plugin de formulaire WordPress / Elementor.
- Liens des icônes sociales du footer et des pages légales.
